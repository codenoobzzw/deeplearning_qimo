\begin{abstract}
这次作业我围绕两个任务搭建了一个可复现实验工程：题目一完成多源 3D 资产生成、统一表示和场景融合；题目二完成 ACT 动作分块策略的跨环境泛化对比。物体 A 使用补拍环绕视频真实跑通 COLMAP+3DGS：90 张抽帧中注册 63 张，训练 1000 步后得到 19133 个 Gaussian，测试集 PSNR/SSIM/LPIPS 分别为 23.9658/0.8707/0.2323。受限于外部模型权重和大规模数据下载条件，threestudio SDS、Zero123 和 Mip-NeRF360 背景训练没有全部跑完；为尽量完成作业要求的完整链路，我补充实现了明确标注的替代实验：生成文本鸭子 mesh、单图杯子 mesh 和类 counter 背景 Gaussian，统一采样并合并为 115133 个高斯点，同时导出多视角漫游视频。题目二方面，我使用老师允许的数据源 \texttt{xiaoma26/calvin-lerobot} 下载了 splitA/B/C/D 每个环境 4 个真实 episode，并调用 LeRobot 源码中的 \texttt{ACTPolicy} 做离线 action chunking 子集实验：ACT-A 在 D 子集上的 mean Action L1 为 0.2779，ACT-ABC 为 0.2546。由于本轮没有完成 70GB 全量数据训练、视觉 CNN 输入训练和 CALVIN simulator rollout，报告中把“真实子集离线实验”和“替代 proxy 实验”分开说明，不把它们写成全量 CALVIN 成功率。
\end{abstract}

\section{任务背景}
3D Gaussian Splatting 将场景表示为显式高斯点云，具有训练和实时渲染效率高的优点\cite{kerbl20233dgs}。DreamFusion 使用预训练 2D 扩散模型和 SDS loss 从文本生成 3D 内容\cite{poole2022dreamfusion}，threestudio 提供了统一实现框架\cite{threestudio2023}。Zero-1-to-3 将单张图像拓展为多视角先验，可用于单图到 3D\cite{liu2023zero1to3}。ACT 通过 action chunking 一次预测未来一段动作，减少逐步预测的高频抖动\cite{zhao2023act}。LeRobot 和 CALVIN 为机器人模仿学习和跨环境泛化提供了工具与数据基础\cite{lerobot2024,mees2022calvin}。

我在实现时优先保证两点：第一，能真实运行的部分尽量跑出结果，而不是只写流程；第二，确实受限于网络、外部权重或数据集下载的部分，采用可复现的替代实验补齐工程链路，并在报告中明确标注。最终完成情况如下：

\begin{itemize}
  \item 真实跑通：物体 A 的 COLMAP+3DGS 重建、渲染和指标计算；CALVIN A/B/C/D 真实 parquet 子集下载与 LeRobot ACTPolicy 离线训练评估。
  \item 替代实现跑通：物体 B/C mesh、背景 Gaussian、Gaussian 级场景融合、漫游视频、ACT 动作分块 proxy 曲线和 D 域评估。
  \item 未直接跑通：官方 threestudio SDS、Zero123、Mip-NeRF360 背景训练，以及全量视觉版 CALVIN ACT 与 simulator rollout，原因主要是外部模型权重、全量数据规模和环境配置成本。
\end{itemize}

\section{数据集与输入}
物体 A 是笔记本电脑。最初输入为 6 张照片，原始文件位于 \texttt{inputs/object\_A/}；这组照片视角覆盖不足，因此主要用于记录失败对照。之后我补拍了 \texttt{inputs/object\_A/A\_video.mp4}，时长约 15.43 秒，共 460 帧。脚本 \texttt{scripts/extract\_frames.py} 以 6 fps 抽帧并按清晰度、近重复阈值筛选，最终从 93 个候选帧中保留 90 张，写入 \texttt{data/object\_A\_video/input/}。图~\ref{fig:object-a-photo} 和图~\ref{fig:object-a-video} 分别展示照片对照组与视频抽帧。

物体 C 是一张黑色保温杯照片，位于 \path{inputs/object_C/cup.jpg}。由于当前 PG 环境没有现成的 rembg、SAM 或 OpenCV 包，本实验使用纯 PIL/NumPy 的启发式前景掩膜，生成 \path{outputs/task1/object_C_image3d/cup_rgba.png}。该结果保留了杯盖、白色提手和鸭子涂鸦，但仍有部分桌面/鼠标垫背景残留，见图~\ref{fig:cup-rgba}。

Mip-NeRF 360 背景优先计划使用 counter 场景\cite{barron2022mipnerf360}，但本轮没有完成大数据下载和背景训练；为保证融合链路可运行，我生成了一个类 counter 的背景替代 mesh 并采样为 Gaussian。CALVIN 数据使用 \texttt{xiaoma26/calvin-lerobot}\footnote{\url{https://huggingface.co/datasets/xiaoma26/calvin-lerobot/tree/main}}。该仓库包含 \texttt{splitA}、\texttt{splitB}、\texttt{splitC}、\texttt{splitD} 四个顶层目录，全量约 69.9GB；本轮为了在时间内得到真实可复现结果，每个 split 下载前 4 个 parquet episode 作为离线子集，分别包含 215、236、260、260 帧，state 维度 15，action 维度 7。

\section{方法}
\subsection{物体 A：COLMAP + 3DGS}
我先用 6 张照片运行 CPU COLMAP 的特征提取、穷举匹配和建图流程。第一次使用清洗后的 5 张图，第二次使用全部 6 张图并放宽初始化内点数、绝对位姿内点数和三角化角度；两次均报告 \texttt{No good initial image pair found}。补拍视频后，我对官方 3DGS 的 \texttt{convert.py} 做 COLMAP 3.6 兼容补丁，移除该版本不支持的全局 BA 参数，再用 90 张视频抽帧运行 COLMAP/undistort。最终 sparse model 注册 63 张图，生成 3289 个稀疏点，平均 track length 为 4.9085，平均重投影误差为 0.8745 px。随后在 base 环境的 PyTorch 2.6.0+cu124 上训练 1000 步 3DGS，并运行渲染与指标计算。

\subsection{物体 B：文本到 3D}
threestudio 官方仓库已克隆，help 命令能运行，并确认存在 DreamFusion 配置文件。计划提示词为：
\begin{quote}
\small a small yellow rubber duck toy, smooth plastic surface, single object, full body, centered, clean 3D asset, no text, no watermark
\end{quote}
但完整训练依赖包含 \texttt{tiny-cuda-nn}、\texttt{nvdiffrast}、\texttt{xformers} 和扩散模型权重。本轮未完成独立 threestudio 环境安装和 SDS 训练。为了让题目一融合链路真实闭合，我实现 \texttt{scripts/generate\_proxy\_assets.py}，根据同一提示词生成一个黄色鸭子 OBJ 替代 mesh，包含 2300 个顶点和 3964 个三角面，并在合并阶段采样为 28000 个 Gaussian。该结果只作为文本到 3D 的可运行替代实现，不作为官方 SDS 结果。

\subsection{物体 C：单图到 3D}
已完成单图 RGBA 预处理，并把图像复制到 \path{third_party/threestudio/load/images/cup_rgba.png}，后续可直接运行 \path{scripts/run_zero123_object_C.sh}。由于未完成 Zero123/Magic123 权重与训练，本轮使用单图几何替代模型：从 RGBA 前景估计主体颜色，以圆柱杯身、杯盖和椭圆手柄先验生成 OBJ mesh，包含 2284 个顶点和 4388 个三角面，并采样为 36000 个 Gaussian。该结果是单图到 3D 的可运行替代实现，不作为 Zero123 真实生成结果。

\subsection{高斯级融合}
工程中实现了 \texttt{mesh\_to\_gaussians.py}、\texttt{transform\_gaussians.py}、\texttt{merge\_gaussians.py} 和 \texttt{render\_merged\_path.py}。其中 mesh 转 Gaussian 按 3DGS PLY 字段写入 \texttt{f\_dc}、\texttt{opacity}、\texttt{scale} 和单位四元数；颜色使用 SH DC 约定 $(rgb-0.5)/0.28209479$。融合时，物体 A 使用真实 3DGS PLY；物体 B/C 和背景替代 mesh 先采样为 Gaussian，再按 \texttt{configs/placements.yaml} 做缩放、旋转和平移，最后按 PLY property 拼接为 \texttt{outputs/task1/merged\_scene/point\_cloud.ply}。CPU 预览渲染器使用稳健取景和点云投影生成多视角漫游视频。

\subsection{LeRobot ACT}
LeRobot 仓库已克隆，轻量依赖安装到 \texttt{local\_pkgs/lerobot} 后，源码方式的 \texttt{lerobot\_train --help} 已跑通。根据数据集 split，我新增 \texttt{scripts/train\_act\_calvin\_subset.py}：先下载真实 CALVIN-LeRobot parquet 子集，再读取 \texttt{state} 和 \texttt{actions}，调用 LeRobot 官方 \texttt{ACTPolicy} 训练长度为 8 的 action chunk。两个真实子集模型使用同一结构和超参数，区别仅为训练域：ACT-A-real-subset 只使用 splitA，ACT-ABC-real-subset 使用 splitA+B+C，最后统一在 splitD 子集上计算 Action L1。由于图像列读取在当前环境中会触发底层 parquet/pyarrow 崩溃，本轮真实子集实验使用 state/environment\_state 输入，不是完整视觉 CNN ACT；另外我仍保留 \texttt{scripts/train\_act\_proxy.py} 作为 proxy 对照。

从机制上看，ACT-A 只在环境 A 上训练，遇到 D 环境时更容易过拟合单一场景的状态分布；ACT-ABC 混合多个环境后，更容易学习跨场景共享的状态-动作关系。Action chunking 的优点是一次预测未来动作片段，能减少逐步预测噪声；风险是首帧理解错误会影响整个 chunk。真实子集实验中 ABC 的 D 域 Action L1 低于 A，proxy 实验中这种差距更加明显，二者方向一致，但真实子集仍太小，不能夸大为完整 CALVIN success rate 结论。

\section{讨论与局限性}
本轮最大局限是输入、网络和时间预算。物体 A 的 6 张照片不足以完成 SfM，但补拍视频说明连续视角覆盖能显著提升 COLMAP 成功率；1000 步 3DGS 属于快速训练，渲染已成形但仍略模糊，后续应延长到 7000--30000 steps，并做更稳定的前景/背景控制。物体 B/C 和背景目前为替代资产，能完成代码级 Gaussian 合并和视频输出，但不具备官方 SDS、Zero123 或 Mip-NeRF360 训练结果的真实性。CALVIN 方面已经下载真实 split 子集并训练 LeRobot ACTPolicy，但还不是全量 70GB 数据、不是图像 CNN 输入，也没有启动 CALVIN simulator 做任务成功率 rollout，因此只能作为真实数据离线 Action L1 结果。
